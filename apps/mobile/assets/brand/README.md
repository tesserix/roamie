# Roamie identity

The R and golden directional arrow are original vector artwork in
`roamie-mark.svg`. The mark remains legible without animation.

PNG variants are rendered from the SVG with ImageMagick. `roamie-icon.png` is
an opaque 1024px app icon; `roamie-mark.png` is the 512px header/splash mark.
The adaptive and monochrome Android variants center a 600px glyph on a
1024px transparent canvas, leaving room for launcher masks.

The native splash is static. The application loading screen animates the travel
icons using the native animation driver and stops for Reduce Motion or a screen reader.
